# 서문성 우주기지 포트폴리오

달 연구기지를 우주선으로 탐험하며 항공우주 연구, 위성 교육, 공학 설계와 3D 창작 활동을 확인하는 인터랙티브 3D 포트폴리오입니다.

## 주요 기능

- Three.js 기반 달 연구기지와 우주선 조종
- 10개 프로젝트·경력 구역 및 정보 패널
- WASD·방향키·모바일 터치 조작
- 기지 지도 기반 빠른 이동
- 반응형 HUD와 접근성 레이블

## 로컬 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 생성됩니다. `main` 브랜치에 반영하면 GitHub Pages 배포 워크플로가 실행됩니다.
